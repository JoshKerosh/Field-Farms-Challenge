# Supabase / PostgreSQL / PostGIS

La base navegable no depende de un proyecto remoto ni de una base local. La configuración se reserva para la próxima etapa; no ejecutar un despliegue como parte del arranque de la web.

La primera integración real deberá agregar en conjunto autenticación, membresías finca/organización, permisos por fila, restricciones de integridad, migraciones y pruebas de acceso. PostGIS almacenará geometrías con referencia espacial explícita. Los permisos y las operaciones atómicas corresponden al backend, no al selector de rol de la interfaz.
